关于隐私与研究口径

答题进度和最近一次结果保存在本机浏览器，刷新后可恢复；清除浏览器数据或点「重新测试」会开始新记录。未连接收集服务时，样本仅保存在当前浏览器；通过 npm start 启动服务时写入 data/responses.jsonl。部署到 Netlify 时由 Functions 写入 Netlify Blobs，原始导出需要 ADMIN_TOKEN。封面来自 AniList 的公开封面地址，口碑数据是构建时快照。
