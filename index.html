关于隐私与研究口径

未连接收集服务时，数据仅保存在当前浏览器；通过 npm start 启动本地服务时，样本写入 data/responses.jsonl。部署到 Netlify 时，样本由 Functions 写入 Netlify Blobs，导出接口要求 ADMIN_TOKEN。部署前请设置强随机密钥，并补充你的隐私说明与数据保留期限。口碑数据是构建时快照，不包含个人评论原文。
